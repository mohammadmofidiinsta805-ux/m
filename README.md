# زمین‌نما — ZaminNama

این مخزن برای دموی پروژه «زمین‌نما» (ZaminNama) است — پلتفرم هوشمند کشف، تحلیل و سرمایه‌گذاری املاک در ایران (تمرکز اولیه: جزیره قشم).

محتوا و ساختار اولیه که قرار است اضافه شود:

- طراحی هویت برند (لوگو SVG/PNG)
- فایل Figma با صفحات اصلی و آرت‌بردها (Hero، صفحه نقشه، صفحه زمین، استودیو AI)
- seed data: 30 رکورد زمین (JSON + GeoJSON محدوده‌ها)
- scaffold پروژه React + Tailwind (RTL-ready) با demo Mapbox و loader برای seed data
- مستندات API و دیتاشمای پیشنهادی (README/SQL)

شعبه‌های پیشنهادی:
- main (پیش‌فرض)
- zaminnama/init (شامل فایل‌های اولیه و seed)

نکته‌ها و گام بعدی:
1. من یک شاخهٔ `zaminnama/init` ایجاد خواهم کرد پس از ایجاد commit اولیه د�� شاخهٔ پیش‌فرض.
2. پس از آن، فایل‌های اولیه (لوگو SVG، seed JSON، scaffold) را به شاخهٔ `zaminnama/init` اضافه می‌کنم.

برای ادامهٔ خودکار، این پیام را تأیید کنید یا اگر می‌خواهید فایل‌ها را در شاخهٔ دیگری قرار دهم نام شاخه را بفرستید.
